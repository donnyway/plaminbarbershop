# Plamin Barbershop

## Deskripsi

Plamin Barbershop merupakan website company profile yang dikembangkan sebagai media promosi digital untuk memperkenalkan layanan barbershop kepada masyarakat. Website ini menyediakan informasi mengenai profil usaha, layanan, galeri hasil potong rambut, testimoni pelanggan, lokasi, serta fasilitas reservasi melalui WhatsApp.

Website dirancang menggunakan konsep modern, minimalis, dan responsif sehingga dapat diakses dengan baik melalui berbagai perangkat seperti desktop, tablet, maupun smartphone.

---

## Tujuan Pengembangan

Website ini dikembangkan dengan tujuan untuk:

- Memperkenalkan Plamin Barbershop kepada masyarakat.
- Menampilkan informasi layanan dan harga secara lengkap.
- Mempermudah pelanggan memperoleh informasi mengenai lokasi usaha.
- Memfasilitasi reservasi melalui WhatsApp.
- Meningkatkan citra dan promosi usaha secara digital.

## Instalasi

Clone repository

```bash
git clone https://github.com/username/plamin-barbershop.git
```

Masuk ke folder project

```bash
cd plamin-barbershop
```

Install seluruh dependency

```bash
npm install
```

Menjalankan aplikasi

```bash
npm run dev
```

Membuat build production

```bash
npm run build
```

Menjalankan hasil build

```bash
npm start
```
